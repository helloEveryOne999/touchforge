# TouchForge

TouchForge 是一款本机 macOS 菜单栏工具，可配置键盘和侧键规则、窗口布局以及标题栏边缘贴靠。它仅使用公开的 macOS API，并将配置保存在：

`~/Library/Application Support/TouchForge/config.json`

## 构建

本机的 Apple Command Line Tools 或 Xcode 必须提供版本匹配的 Swift 编译器与 macOS SDK。

```sh
cd /Users/super/Documents/touchforge
swift test
zsh scripts/package-app.sh
open dist/TouchForge.app
```

可运行的应用包位于 `dist/TouchForge.app`。

## 快捷键示例

TouchForge 可以通过应用的 Bundle ID 启动本机应用。PhpStorm 的 Bundle ID 是 `com.jetbrains.PhpStorm`。

要配置全局 `Command + 1` 启动并前置 PhpStorm：

1. 打开 TouchForge 的“映射规则”页，点击“添加规则”。
2. 选择“键盘快捷键”，按键选择 `1`，仅勾选 `Command`。
3. 在“执行动作”中选择“启动应用”，点击“选择应用…”并选择 PhpStorm。
4. 关闭“仅在指定应用中生效”并保存规则。

界面会显示 `⌘ 1 → 打开 PhpStorm`。其他按键可通过名称选择，未知按键仍可填写原始按键码；应用标识也支持手动填写。

该规则会拦截所有应用中的 `Command + 1`。如果希望保留其他应用的同一快捷键，请停用或删除此规则。

## 修饰键与妙控鼠标滑动

安装新版后，会保留现有规则并追加三条推荐手势。在妙控鼠标**触摸表面**滑动：

- `Option + 上划 → 调度中心`，等效于触摸板四指上划。
- `Command + 左划 → 左侧桌面／全屏窗口`。
- `Command + 右划 → 右侧桌面／全屏窗口`。

左右切换等效于 macOS `Control + ← / →`，每次滑动只切换一个空间。需要系统“键盘 → 键盘快捷键 → 调度中心”中的“向左／右移动一个空间”启用并使用这两个快捷键；没有相邻空间时保持当前空间。

0.1.3 修正方向键的 Function／NumericPad 标志，并发送完整的修饰键转换事件，在桌面切换期间暂时释放并恢复实际按住的 Command。可在“权限与状态”查看最近识别到的手势；“动作已发送”不代表系统一定已切换空间。

在“映射规则 → 添加规则”选择“鼠标滑动”，可绑定上、下、左、右四个方向，指定 Control、Option、Shift 或 Command 组合，并选择发送按键、窗口布局、启动应用或系统操作。系统操作包括调度中心和切换到左／右侧桌面。

方向按手指实际运动定义，不受“自然滚动”设置影响。滑动达到触发距离后执行一次，惯性不重复执行；未按匹配的修饰键时滚动正常通过。使用连续滚动事件，普通离散滚轮或单纯移动鼠标指针不触发；触摸板等连续滚动设备也可能触发这类规则。

## 登录启动和 DMG

从“应用程序”首次启动时，会注册系统登录项；“通用设置”显示真实状态并可随时关闭。自动启动时常驻菜单栏，不主动打开配置窗口。

`dist/TouchForge-0.1.3-arm64.dmg` 为 Apple 芯片、macOS 14 及以上系统的中文拖拽安装包。它使用本地临时签名，未使用 Developer ID 证书，也未经过 Apple 公证。

重新打包需要 Python 的 `ds-store==1.3.2` 和 `mac-alias==2.2.3`，可安装到独立工具目录，再通过 `PYTHONPATH` 与 `TOUCHFORGE_DMG_PYTHON` 指定后运行 `zsh scripts/package-dmg.sh`。

## 权限

TouchForge 不会在启动时请求权限。请在“权限与状态”中点击“检查授权”打开 macOS 授权与设置页面：

- “辅助功能”允许应用移动和调整当前聚焦窗口的大小。
- “输入监控”允许应用观察并重映射全局键盘和侧键输入。

两个授权提示和设置页面均由 macOS 提供。TouchForge 不会尝试静默授予权限。

权限页分别显示辅助功能、输入监控的检测结果，并显示实际事件监听状态。返回应用时自动检测；配置窗口打开时每 3 秒刷新一次，授权生效后会重新尝试启动监听。

当前本机打包采用临时签名，重新编译会改变签名身份。系统设置中的旧开关可能仍为开启，但不适用于新版本；请核对当前应用路径，必要时由用户重新添加新版应用。应用不会修改系统授权记录，也不会把无效授权显示为已授权。

## 手动验证

1. 添加一条 `Command + 1` 到“启动应用”的规则，Bundle ID 填写 `com.jetbrains.PhpStorm`；确认 PhpStorm 被启动或前置，并且按键没有传递给原应用。
2. 添加一条键盘规则，将 Caps Lock（按键码 `57`）映射为 Escape（按键码 `53`）；确认它只发送一次 Escape，不会循环触发。
3. 添加一条鼠标按键 `3`、`4` 或 `5` 到“左半屏”的规则；确认可调整大小的聚焦窗口移动到当前显示器的左半屏。
4. 为规则指定应用 Bundle ID，确认只有在该应用位于前台时规则才会运行。
5. 启用拖拽贴靠，将窗口标题栏拖到屏幕边缘；确认半透明预览与松开鼠标后的最终布局一致。
6. 在各个角落和第二台显示器（如有）上重复验证。
